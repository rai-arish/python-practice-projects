# Python Student Record Management System

## About the Project

This project is a beginner-friendly Python program that stores and manages student information using dictionaries.

It takes student details as input and stores them in a structured format using each student's roll number as a unique key.

## Features

- Takes input for multiple students
- Stores student names, ages, classes, roll numbers, and marks
- Uses dictionaries to organize student records
- Validates user input
- Handles invalid inputs 

## Technologies Used

- Python 3
- Dictionaries
- Loops (`while` and `for`)
- Conditional statements (`if`, `elif`, `else`)
- Exception handling (`try-except`)
- String methods such as `.strip()` and `.isalpha()`

## How to Run

1. Install Python 3.
2. Clone this repository or download the project files.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python students.py
```

If your system uses the Python launcher, you can also try:

```bash
py students.py
```
